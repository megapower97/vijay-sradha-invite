IMPORTANT FOLDER STRUCTURE INSTRUCTIONS:

1. IMAGES:
   Put your images in the `public/images/` folder.
   Ensure they are named EXACTLY like this (note the .jpg extension):
   - godavari-road-rail-night.jpg
   - iskcon-blue-night.jpg

2. SOUND/AUDIO:
   Put an audio file named EXACTLY `music.mp3` directly into the `public/` folder. 
   When you tap "Tap to light the diyas", it will look for this file and play it automatically!
